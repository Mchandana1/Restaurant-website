# 🍽 Foodie Palace

A simple restaurant website built using **HTML** and **CSS**.

#Features
 Home page with a welcoming hero section
 Menu page displaying food items and prices
 About Us page with restaurant information
 Contact page with a customer inquiry form
 Modern and responsive user interface
 Navigation bar for easy page navigation
 Hover effects and clean styling using CSS

## Technologies Used

* HTML5
* CSS3

## Project Structure

```text
Restaurant-Website/
│── index.html
│── menu.html
│── about.html
│── contact.html
│── style.css
└── images/
```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open **index.html** in your web browser.
